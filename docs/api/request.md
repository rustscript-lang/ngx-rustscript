# Request and variables

[Documentation](../index.md) · [Directives](../directives.md) · [API](index.md) · [Execution model](../execution-model.md) · [Security](../security.md) · [Examples](../examples/index.md) · [Compatibility](../ngx-api-compatibility.md)

All request-read hosts copy ngx_str / list / buffer bytes into
owned VM values on the worker main thread and never retain request, pool,
or list pointers. They require a live request scope. `ngx::req::read_body`
is async (`Waiting`); the rest of this family is sync.

```rss
struct RequestHeadersResult {
    headers: map,
    truncated: bool
}

struct RequestArgsResult {
    args: map,
    truncated: bool
}
```
